# Privacy Policy — Mian's Oura

**Effective Date:** October 12, 2026

Mian's Oura is a personal, non-commercial application used to access and analyze Oura Ring health and wellness data.

**Data Access:** The application accesses authorized Oura data through the Oura API, including sleep, readiness, heart rate, activity, and other health metrics.

**Data Storage:** The ouracli tool stores authentication credentials locally using the operating system's secure credential storage, with an encrypted-file fallback where necessary. Health data may be retained locally if explicitly exported or saved.

**Data Sharing:** This application does not sell user data or use it for advertising. If the user explicitly connects an external AI service, selected health data may be transmitted to that provider for analysis, subject to its privacy practices.

**Data Retention and Deletion:** Access can be revoked through Oura's connected application settings. Any locally saved or exported health data can be deleted by the user.

**Contact:** For privacy inquiries, contact the application owner using the email listed in the Oura developer registration.
